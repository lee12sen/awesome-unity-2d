# Awesome Unity 2D


## 간단한 프로젝트 설명 (Description)
> 유니티 2D 횡스크롤 게임 개발에 유용한 무료 에셋, 튜토리얼, 도구 모음

유니티로 2D 게임을 처음 만들 때 "그래픽은 어디서 구하지?", "타일맵은 뭘로 그리지?" 같은 고민에 시간을 많이 쓰게 됩니다.
이 저장소는 직접 써 보고 유용했던 **무료 자료**를 분야별로 정리해, 다른 개발자들이 같은 시간을 아낄 수 있도록 돕는 것을 목표로 합니다.

## 주요 내용 (Features)

- 2D 게임에 바로 쓸 수 있는 **무료 그래픽·사운드 에셋** 사이트
- 픽셀아트, 타일맵 제작에 쓰는 **무료 도구**
- 유니티 2D 기능을 배울 수 있는 **공식 문서와 튜토리얼**
- 누구나 Pull Request로 자료를 추가할 수 있는 **오픈 기여 구조**

## 공식 문서 및 학습

- [Unity Manual](https://docs.unity3d.com/Manual/index.html) - 유니티 공식 매뉴얼. 2D 관련 항목(Sprite, Tilemap, 2D Physics)을 찾아볼 때 기본이 되는 문서.
- [Unity Learn](https://learn.unity.com/) - 유니티 공식 무료 학습 플랫폼. 2D 게임 입문 코스가 있음.

## 그래픽 에셋

- [Kenney](https://kenney.nl/assets) - 상업적 사용까지 자유로운 CC0 라이선스의 2D 에셋을 대량으로 제공.
- [OpenGameArt](https://opengameart.org/) - 커뮤니티가 공유하는 오픈 라이선스 게임 그래픽 모음. 에셋마다 라이선스가 다르므로 확인 필요.
- [itch.io 무료 게임 에셋](https://itch.io/game-assets/free) - 인디 제작자들이 올린 무료 스프라이트, 타일셋 모음.
- [Unity Asset Store](https://assetstore.unity.com/) - 유니티 공식 에셋 스토어. 가격 필터를 "무료"로 설정해 2D 에셋을 찾을 수 있음.

## 사운드 에셋

- [Freesound](https://freesound.org/) - 효과음을 검색해 받을 수 있는 대형 사운드 공유 사이트.
- [jsfxr](https://sfxr.me/) - 점프, 코인, 피격 같은 레트로 효과음을 브라우저에서 바로 만들어 주는 도구.

## 제작 도구

- [Piskel](https://www.piskelapp.com/) - 브라우저에서 바로 쓰는 무료 픽셀아트·스프라이트 애니메이션 편집기.
- [Aseprite](https://www.aseprite.org/) - 픽셀아트 제작에 가장 많이 쓰이는 도구 (유료, 소스 직접 빌드 시 무료).
- [Lospec Palette List](https://lospec.com/palette-list) - 픽셀아트용 색상 팔레트 모음.
- [Tiled](https://www.mapeditor.org/) - 무료 오픈소스 타일맵 에디터.
- [LDtk](https://ldtk.io/) - 2D 레벨 디자인에 특화된 무료 레벨 에디터.

## 유니티 패키지

- [DOTween](https://dotween.demigiant.com/) - 이동, 크기, 색상 변화 같은 연출을 코드 한 줄로 만들어 주는 트윈 라이브러리 (무료 버전 제공).

## 읽을거리

- [Game Programming Patterns](https://gameprogrammingpatterns.com/) - 게임 코드에서 자주 쓰는 디자인 패턴을 설명한 책. 웹에서 무료로 읽을 수 있음.

## 사용 방법 (Usage)

1. 위 목차에서 필요한 분야를 찾습니다.
2. 링크를 눌러 자료를 확인합니다.
3. 에셋을 게임에 사용할 때는 **각 사이트와 에셋의 라이선스를 반드시 확인**하세요. 이 목록의 라이선스(MIT)는 목록 자체에만 적용되며, 링크된 자료의 라이선스는 각각 다릅니다.

## 설치 (Installation)

별도 설치가 필요 없는 문서형 저장소입니다. 웹에서 바로 보거나, 로컬에 받아 두고 싶다면 아래 명령어를 사용하세요.
